A few steps. Many fewer keystrokes.

The Chrome Web Store installation link will be added after publication. Development installation requires a copy of the extension source from the maintainer.

  1. Use Chrome 135 or later. Open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the extension folder containing manifest.json.
  3. Click the Autofill toolbar icon to open settings. Add a rule with a page URL, field selector, and value.
  4. Open the practice forms, reload after saving your rules, and check the filled result.

You set the rules.

Is Autofill free?

Yes. The current extension is free to use, with no subscription or account requirement.

Does it work on every website?

Compatibility depends on the form and its controls. Chrome restricts extensions on internal pages and some protected pages. Complex widgets may need additional configuration.

Where does my information go?

Saved rules stay in local extension storage. Filled values become available to the website you fill. Clipboard rules and custom scripts need particular care. Read the privacy policy for details.
